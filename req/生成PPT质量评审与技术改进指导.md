## 1. 三类问题（验收时只认这三类）

| 类 | 含义 | 对外影响 |
|---|---|---|
| **A 张冠李戴** | 数字/店名/价位来自源文档，但口径实体（大盘/衬衫/polo/单品）错绑 | 事实性错误，一票否决 |
| **B 坏填充** | 截断碎片、内部标记残留、同文填两卡、未替换槽位 | 成品不可交付 |
| **C 覆盖不足** | 源报告关键 KPI/章/榜/图未进入成品 | 信息量断崖，弱于源报告 |

**通过标准（本样例）**：A=0；B=0；C 至少覆盖下表「必中项」。

## 2. 逐页问题清单（回归对照）

复验时用本表做 diff：同一页若再出现同类症状 → 对应门禁未生效或证据未入库。

### A 类：数据错误

| 页 | 症状 | 源事实（正确口径） |

| P10 | 郗思昙 1.4 万、金玖 2.6 万 | 源 P5：郗思昙约 2.6/2.3 万，金玖约 2.0 万；1.4 万属其它店。**店名×销量交叉错配** |
| P12 | 「腰腹加宽…卡帝乐鳄鱼辰川」 | 卡帝乐鳄鱼属 **polo 榜**（源 P3）；腰腹加宽衬衫趋势首款是罗蒙（源 P7）。**跨页跨品类拼贴** |

### C 类：必中覆盖（漏则判 C）

| 必中项 | 源位置 | 说明 |
|---|---|---|
| polo 大盘 KPI | 源 P2 | 销量 **403.7 万**、销售额 **3.9 亿**及同比（如 +26.9% / +36.3%）须出现在规模/增速相关页，且口径写清 polo |

## 4. 复验操作清单（每次改管线后跑）

1. **重启后端**（检索/OCR 改动后）；前端刷新后再生成。
2. 用固定主题生成大纲→灌模（采样窗 + 商务男装衬衫/polo）。
3. 对照 §2：
   - [ ] 大盘页无 296.2 / 403.7 冒充大盘
   - [ ] 衬衫页 KPI 口径含「衬衫」；polo 页含 polo KPI
   - [ ] 无 `progress*`、无孤立两三位数字碎片、无同文双卡
   - [ ] 价格带 tip 点名价区（如 ￥50-100）
4. 若仍有 A：先查该页检索 `docs` 是否含正确实体段 → 无则查入库/加权；有则查忠实性校验是否未触发。
5. 将本轮结果（通过/失败页码）记回设计文档 §10.4 或本文件文末「复验记录」。

## 5. 优先级（与设计文档对齐，不另起炉灶）

| 优先级 | 做什么 | 主要消灭 |
|---|---|---|
| **P0** | 数值忠实性 + 标题实体检索收紧；表格原子 chunk（重入库） | A、B 碎片根因 |
| **P1** | JSON 双轨直填；跨槽去重/标记过滤加固 | C 数据页、B 残余 |
| **P2** | 版式路由、裁图、四指标 eval | C 表现力、回归自动化 |

Eval 四指标（P2）：**数值准确率 / 覆盖率 / 坏填充率 / 幻觉率**——本文件 §2 即衬衫样例的人工金标。
