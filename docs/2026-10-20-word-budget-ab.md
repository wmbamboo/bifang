# 段落字数指令 A/B 实测（2026-10-20）

> 目的：校准十四·3.4 的字数变量方案——**「字数要不要写进 prompt」**以及**「`budget = 150 + 60×要点数` 的系数是否合适」**。
> 这两条此前在交接里标注为「经验判断·未实测」，本文用真实 LLM 调用把它变成实测数据。

## 一、方法

| 项 | 取值 |
|---|---|
| 模型 | `deepseek-chat`（后端 `.env` 同款），temperature 0.7 |
| 输入 | 10 个真实结构的段落（4 章；要点数分布：0 点 ×2、1 点 ×6、2 点 ×2） |
| 变量 | 只有「字数指令」一项，其余 prompt 完全相同 |
| 材料 | 一份固定材料摘要喂给所有段（不接检索） |
| 样本 | 3 档 × 10 段 = 30 次调用，全部成功 |
| 字数口径 | 中文字符数 + 拉丁词数 |

三档定义：

| 档 | 指令 |
|---|---|
| A | **不给任何字数指令** |
| B | 「撰写 200~400 字的正文。」（现状写法：区间常数） |
| C | 「撰写约 N 字的正文。」N = clamp(150 + 60×要点数, 150, 600)（变量化方案） |
| D | 同 C，但 base = 170（用于校准 base，补跑 10 次） |

## 二、结果

| 档 | 均值 | 中位 | 标准差 | CV | 命中率(±20%) | 最短/最长 |
|---|---|---|---|---|---|---|
| A 不给字数 | 352.4 | 321 | 114.3 | **0.32** | 40% | 169 / 571 |
| B 200~400 | 336.9 | 348 | 39.1 | 0.12 | **20%** | 260 / 392 |
| C 约 N 字（base 150） | 220.8 | 222 | 35.2 | 0.16 | **90%** | 143 / 273 |
| D 约 N 字（base 170） | 249.5 | 246 | 31.3 | 0.13 | 70% | 199 / 291 |

按要点数拆开看偏差（实际 vs 目标，%）：

| 段类型 | A | B | C |
|---|---|---|---|
| 2 要点（目标 270） | +19% / −6% / +18% | +8% / −4% / +30% | −1% / +1% / −11% |
| 1 要点（目标 210） | +90% / −20% / +172% / +42% / +54% | +45% / +83% / +65% / +70% / +69% | +7% / +3% / +6% / −0% / +6% |
| 0 要点（目标 150，结论章） | +129% / +253% | +161% / +120% | +27% / −5% |

## 三、结论（五条）

1. **字数必须写进 prompt，且必须是单值变量。** C 档命中率 90%，B 档 20%，A 档 40%。
2. **修正旧经验判断：不给字数不是"偏短"，是"偏长且失控"。** A 档均值 352 字、区间 169~571、CV 0.32（B 档的 2.7 倍）。长度被材料量牵着走，而不是被段落需要牵着走。
3. **「200~400」这种区间写法必须废弃。** 它的 CV 最低（0.12）是**假整齐**——所有段被挤到 300~350，代价是与段落实际需要脱钩：0 要点的结论段被写到 330~392 字（目标 150，超写 120%~161%）。CV 低不等于对。
4. **公式 `150 + 60n` 实测成立，base 保持 150。** 校准档 D（base 170）命中率反而降到 70%，且 0 要点段仍超写（+17%/+32%）⇒ 问题不在 base 大小。每点 60 字的斜率在 1~2 要点段上偏差普遍在 ±10% 内。
5. **唯一残留偏差：0 要点的结论段仍偏长（C 档 +27%）。** 建议在结论章单独下调（如 ×0.85 或 base 130），**该建议未实测**，如需严谨可补跑 2 段。

## 四、对交接文档的影响

- 十四·3.4 的公式**确认不变**：`budget = 150 + points × 60`，clamp `[150, 600]`。
- 十四·3.4 里「不给字数 LLM 会偏短且段间方差大」这句**更正为**「偏长且失控（CV 0.32）」。
- 「实测模型易取下界」这句**更正为**「区间写法让所有段挤向区间中段（约 336 字），与段落需要脱钩」。
- 十五·2 体量轴的 `N = 总字数 ÷ 300` 可沿用（实测均值 220~350 与此同量级）。

## 五、局限

- 单模型（deepseek-chat）、单主题（polo 衫）、单份材料，n=10 段；换模型需重跑。
- 未接真实检索（固定材料），只测「字数指令对长度的控制力」，**不评价内容真实性**。
- 未做重复采样（每段每档 1 次），单次波动未分离。

## 七、真实大纲复跑（2026-10-20 二次实验）

用户提供真实大纲《抖音商务衬衫polo选品分析》：4 章 / 13 段 / 29 要点，**要点数全部为 2~3（无 0 要点段）**。
本次材料改用大纲自带的真实要点（不再用虚构摘要），13 段 × 3 档 = 39 次调用，全部成功。
完整正文对照见 `docs/2026-10-20-ab-samples.md`。

| 档 | 均值 | CV | 命中率 | 最短/最长 | 样例大纲（要点 0~2）对比 |
|---|---|---|---|---|---|
| A 不给字数 | 220.5 | 0.18 | **23%** | 155 / 307 | 352.4 / 0.32 / 40%（**偏长**） |
| B 「200~400」 | 294.4 | 0.14 | **77%** | 232 / 374 | 336.9 / 0.12 / 20%（系统性超写） |
| C 「约 N 字」 | 299.5 | 0.17 | **77%** | 204 / 402 | 220.8 / 0.16 / 90% |

目标均值 297.7；C 档均值 299.5、B 档 294.4 均对准，A 档 220.5 系统性偏短 26%。

### 两条结论修正

1. **A 档不是固定"偏长"，而是"长度由材料量决定"。** 样例大纲材料是一份长摘要 → 352（偏长）；真实大纲材料只有 2~3 条要点 → 220（偏短）。统一表述：**不给字数 ⇒ 长度由材料量牵着走，不由段落需要决定。**（覆盖第六节第 1 条的"偏长"表述）
2. **B 档这次 77%，与 C 持平。** 因为该大纲所有段目标都是 270~330，恰好落在「200~400」的中段。样例大纲里有 0 要点段（目标 150），B 档才塌到 20%。
   ⇒ **变量化的真实收益 = 应对要点数不均匀的大纲**，尤其是含 0 要点结论段时，B 档会系统性灌水（实测 20% vs 90%）。

### 对结论的影响

- **字数变量仍然要保留，但理由要改**：不是"均值更准"（均匀大纲下 B/C 打平），而是**抗不均匀 + 防灌水**。
- 从正文质量看（见样例文档）：C 档在「polo衫主力价格带」写了 316 字，把三个价格带逐个解读并给出「主战场 / 流量入口 / 溢价试探」的主次布局；A 档 216 字只有罗列、无结论；B 档 240 字同样收不住尾。「属性配置取舍」一段 B 档被灌到 374 字（目标 270，+39%），出现明显重复啰嗦。
- 公式 `150 + 60n` 在真实大纲上依然成立：目标均值 297.7 vs 实际 299.5。


## 八、结论章 ×0.85 验证（E 档）——**证伪，不落地**

### 8.1 为什么补这一轮

第七节留下一条残留：0 要点结论段在 C 档仍超写 +27%，建议「结论章 ×0.85」。该建议当时**只有 1 段、单次采样**支撑，未经验证。本节把它跑成实测。

### 8.2 方法

- E 档 = C 档基础上，**章标题命中 `结论|建议|总结|结语|行动|下一步`** 的段落，指令字数 ×0.85（如目标 270 → 指令 230，目标 150 → 指令 128）
- 命中率仍按**原始目标**（`150+60n`）计算——即检验「打折后是否更接近应有的长度」，而不是检验「是否听指令」
- 两份大纲 × C/E 两档，同批次并发，**并同时重跑 C 档**作为同批对照（共 46 次调用）

### 8.3 结果

| 大纲 | 段数 | C 档命中率 | E 档命中率 | C 均值 | E 均值 |
|---|---|---|---|---|---|
| 样例（要点 0~2） | 10 | **100%** | 90% | 222.1 | 232.4 |
| 真实 polo（要点 2~3） | 13 | **92%** | 69% | 290.9 | 277.9 |

真实大纲结论章三段（目标均为 270，E 档指令 230）：

| 段 | C 档实际 | 偏差 | E 档实际 | 偏差 |
|---|---|---|---|---|
| 主推与试单分层 | 259 | −4% | **181** | −33% |
| 属性配置取舍 | 265 | −2% | 253 | −6% |
| 暂缓与观察 | 255 | −6% | **191** | −29% |

样例大纲结论章两段（目标 150，E 档指令 128）：C 档 155 / 156（+3% / +4%），E 档 149 / 138（−1% / −8%）。

### 8.4 两个结论

**结论一：×0.85 不该落地。** 两份大纲一致显示 E 档劣于 C 档（100%→90%、92%→69%）。真实大纲里结论章本来在 C 档就命中（−2%~−6%），打折后反被压到 −29%~−33% 脱靶。**第十七章 17.4 的「结论章 ×0.85」提议予以撤销。**

**结论二（更重要）：「0 要点段 +27% 超写」是噪声，不是系统偏差。**
本轮重跑同一段（样例大纲「优先方向」，目标 150）：上一批 190 字（+27%），本批 **155 字（+3%）**。同一条指令、同一个模型，两次差 35 字。

### 8.5 噪声量化（**本节最有价值的产出**）

把两份大纲的 C 档新旧两批逐段相减（指令完全相同，唯一变量是采样）：

| 大纲 | 逐段差值标准差 σ | 相对均值 | 单段最大偏差 |
|---|---|---|---|
| 样例（10 段） | 19.5 字 | **8.8%** | −35 字（−16%） |
| 真实（13 段） | 42.1 字 | **14.0%** | −95 字（−29%） |

**即：单次采样的段落字数噪声 σ ≈ 9%~14%。**

由此得到一条判据，适用于本项目后续所有 prompt A/B：

> **单次观测到的效应必须显著大于 2σ（约 20%~28%）才可采信；低于此值的差异一律当作噪声，不许据此改 prompt。**

用这条判据回检前面的结论：

| 结论 | 效应量 | 样本 | 判定 |
|---|---|---|---|
| B 档区间写法系统性超写（1 要点段 +45%~+83%、0 要点段 +120%~+161%） | 远超 2σ | 5~8 段一致同向 | **成立** ✓ |
| A 档长度由材料量牵引（352 vs 220，跨材料差 130 字） | 远超 2σ | 两批一致 | **成立** ✓ |
| C 档无明显系统偏差（逐段 ±11% 内） | 在 σ 内 | 23 段 | **成立**（无偏差也是结论）✓ |
| 0 要点结论段 +27% 超写 | 约 1.3σ | 1 段 × 1 次 | **不成立，已证伪** ✗ |

### 8.6 局限

- 噪声估计基于每档**单次采样**，σ 本身是粗估；要精确需同指令重复 3~5 次
- 本章所有结论仍限于单模型（deepseek-chat）、单主题（服装选品）、固定材料（不接检索）
- 命中率阈值 ±20% 与噪声 σ≈9%~14% 同量级，因此**单段命中率波动大**，应以「整档均值 + 多段一致性」判读，不以单段论成败


## 九、附带发现：开头句式同质化（与字数指令无关）

扫描脚本 `.workbuddy/tools/style_scan2.py`（对任意 docx）、`tier_style.py`（对 A/B 原文）。

| 样本 | 套路开头 | 模糊词/段 |
|---|---|---|
| A 档（不给字数） | 85% | 0.8 |
